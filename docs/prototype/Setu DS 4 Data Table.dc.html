Anatomy & rules

  • Sticky header and totals. Totals cover every row that matches the filters, not just the page.
  • Inline edit is marked with a dashed underline. A saved edit shows a spinner until the server confirms, then a check.
  • Row status is a pill with icon and text. Due amounts are bold and amber, never colour alone.
  • Bulk actions replace the filter row's focus with a dark bar. Actions the user can't perform are shown locked with the reason.
  • Money columns are right-aligned with tabular figures and South Asian grouping.
