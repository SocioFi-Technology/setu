Actions & inputs কাজ ও ইনপুট

Every control is keyboard-reachable with a visible focus ring. Desktop controls are 40px; tablet and mobile use 48px. Bangla labels come first, English follows after a middle dot; in single-language mode only the chosen language shows. The phone, date, money and dose fields below are live.

2.1

Buttons

One marigold key action per screen at most. Primary teal for the main save path. Danger is only for irreversible or money-reversing actions and always opens a confirmation.

Variants × states

Error is not a button state: a failed action keeps the button enabled and shows an inline alert with Retry (see page 5).

Inputs

Labels sit above fields and are never replaced by placeholders. Help text sits below; errors replace help text and say how to fix the problem.

Text input states
